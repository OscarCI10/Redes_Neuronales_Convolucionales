# Redes_Neuronales_Convolucionales
El presente trabajo tiene como objetivo realizar una introducción a las redes neuronales
convolucionales y a su aplicación a la clasificación de imágenes.
En primer lugar, presentaremos la estructura de las redes neuronales prealimentadas
con una única capa oculta, para posteriormente generalizar dicha estructura a las redes
neuronales prealimentadas multicapa. En este contexto, explicaremos los métodos más
comunes para entrenar una red neuronal, introduciendo la noción de función de error y
presentando el método del descenso estocástico del gradiente y el método de retropropagación.
A continuación, presentaremos las redes neuronales convolucionales y explicaremos su
relevancia para la clasificación de imágenes.
Ilustraremos la implementación de una red neuronal convolucional y sus ventajas respecto
a arquitecturas de redes neuronales más genéricas, en un ejemplo de clasificación
con 10 clases, utilizando el conjunto de datos MNIST, que contiene 70.000 imágenes de
dígitos escritos a mano del 0 al 9.

Palabras clave: Red neuronal convolucional, red neuronal prealimentada, método de
retropropagación, MNIST y función de error.
